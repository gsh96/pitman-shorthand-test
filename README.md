# Pitman shorthand test

This is an early test of a rules-based Pitman New Era shorthand stroke engine (English, as taught for SSC steno). It is a static web page that draws outlines as vector SVG in the browser.

The engine supports only the listed sample words and grammalogues. Outlines marked UNSURE have not yet been checked against a New Era textbook.

Live page: https://gsh96.github.io/pitman-shorthand-test/
