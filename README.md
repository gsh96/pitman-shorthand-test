# Pitman shorthand test

This is an early test of a rules-based Pitman New Era shorthand stroke engine (English, as taught for SSC steno). It is a static web page that draws outlines as vector SVG in the browser.

The engine supports the listed sample words, the New Era grammalogue list and the special list of contractions (Grammalogues tab, with a Contractions filter; the main search box finds them too). Unmarked outlines have been compared with the printed outline (shape overlay) and match it. Outlines marked UNSURE are drawn but still differ from print in some detail; the reason is shown with each one. Current status: 192 grammalogue entries (167 confirmed, 25 UNSURE) and 175 contractions (100 confirmed, 75 UNSURE); nothing is left undrawn.

Live page: https://gsh96.github.io/pitman-shorthand-test/

## Sources and copyright

All outlines are generated by our own rules-based engine from Pitman New Era theory (stroke shapes, vowel places, positions and grammalogue rules). No book content is reproduced: no scanned images, page text or printed outlines from any book are included in this app or repository. Theory was checked against public-domain New Era texts on archive.org (Pitman's Shorthand Instructor, New Era ed., 1920; Pitman Shorthand Instructor and Key, 1955, Digital Library of India; Course in Isaac Pitman Shorthand, Canadian New Era ed., 1924).

The grammalogue and contraction data (`engine/grammalogues.js`, `engine/contractions.js`) is our own compilation of facts: each word, the stroke or sign used for it, its position and the book page where it was checked. It is not a copy of any printed list.

Stroke proportions (`engine/calibration.js`: stroke lengths and angles, hook, circle, loop and shun sizes, line weights) are numbers we measured from the public-domain scans and then tuned by overlaying the engine's own drawings on them locally. Only the resulting numbers are in this repository; the scans and comparison images are not.
